
# FitLog — Workout Library

**FitLog** is a responsive workout library web application built to help users explore exercises, view detailed workout instructions, create a daily workout plan, and save workouts for later. It features a clean dark theme with lime-green accents and a user-friendly interface across mobile, tablet, and desktop devices.

## 🌐 Live Demo

**Visit FitLog:** https://chic-pegasus-3c6407.netlify.app/

## 🛠️ Technologies Used

- **Next.js** — React framework for building the web application
- **React** — Component-based user interface
- **JavaScript** — Application logic and interactivity
- **Tailwind CSS** — Responsive styling and layout
- **REST API** — Fetching workout data
- **Local Storage** — Persisting planned and saved workouts
- **Netlify** — Deployment and hosting

## ✨ Key Features

1. **Workout Library** — Browse workouts with images, muscle groups, equipment, duration, calories burned, and ratings.
2. **Workout Details** — View workout descriptions, difficulty levels, equipment, and step-by-step instructions.
3. **Daily Workout Plan** — Add up to five workouts to your daily plan and mark completed exercises as done.
4. **Save for Later** — Save workouts for future reference and remove them whenever needed.
5. **Responsive Design** — Access the workout library on mobile phones, tablets, and desktop screens.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/TakiaNova/fit-log.git
```

Navigate to the project directory:

```bash
cd fit-log
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## 🏗️ Production Build

To create an optimized production build, run:

```bash
npm run build
```
